# Syllogia Team Website

This repository contains the source code for the Syllogia team website, a collaborative platform for knowledge sharing and team collaboration.

## About Syllogia

Syllogia is a collaborative platform designed to enhance knowledge sharing and team collaboration. We bring together teams to share ideas, collaborate on projects, and build knowledge together.

## Website

The website is built using Jekyll and hosted on GitHub Pages.

Visit the site at: https://syllogia-team.github.io/syllogia-team/

## Local Development

To run the site locally:

1. Install Ruby and Bundler
2. Install dependencies:
   ```bash
   bundle install
   ```
3. Run the Jekyll server:
   ```bash
   bundle exec jekyll serve
   ```
4. Open your browser to `http://localhost:4000`
